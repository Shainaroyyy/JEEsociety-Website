# JEEsociety Website

A user-centered website designed for JEEsociety to improve credibility, trust, and clarity for students exploring the platform. This project focuses on structured UI/UX decisions, clean design, and seamless information flow — built collaboratively using **Graphy** and **Hostinger**.

This website was approached like a **product**, not just a website, focusing on how a student feels, navigates, and decides while browsing.

💡 Why This Website Matters

JEE Society needed a website that:
- Communicates clearly with students
- Builds instant trust and credibility
- Explains offerings simply and effectively
- Supports conversions and engagement

This website was approached like a **product**, not just a website, focusing on how a student feels, navigates, and decides while browsing.

---

🧩 Design Approach

We followed a structured, outcome-driven workflow:

1️⃣ Understanding requirements & user expectations  
2️⃣ Planning website structure and information hierarchy  
3️⃣ Wireframing layouts and defining key sections  
4️⃣ Designing with clarity, readability, and trust in mind  
5️⃣ Executing using no-code tools for fast and efficient delivery  
6️⃣ Iterating collaboratively through feedback  

---

🛠️ Tools & Platforms Used
- Graphy — No code website creation and UI structuring
- Hostinger — Hosting & deployment 
- **Design Principles** — Responsiveness, readability, visual hierarchy  

These platforms allowed rapid execution without compromising user experience.
